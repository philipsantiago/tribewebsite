# Tribe

The website for Tribe, a social screen-time app for iOS: friends form a tribe,
agree on a daily limit, and pass or fail the day together. Each member's monkey
shows how their day is going.

- Website: https://philipsantiago.github.io/tribewebsite/
- Privacy, in plain words: https://philipsantiago.github.io/tribewebsite/privacy.html
- App prototype: https://philipsantiago.github.io/tribewebsite/prototype/

This repository holds only the published pages. The app is developed elsewhere.
